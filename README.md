# Circuit-Simulation

A collection of electronic circuit simulation files (`.ms14`) covering analog electronics topics such as:

- Rectifiers
- Biasing circuits
- RC filters (low-pass, high-pass, band-pass, band-stop)
- Integrator and differentiator circuits
- Operational amplifier configurations
- Oscillator and amplifier stages

## Repository Contents

Each `.ms14` file represents an individual circuit design/simulation, for example:

- `Half-Wave Rectifier.ms14`
- `Full-Wave Rectifier.ms14`
- `Inverting Amplifier.ms14`
- `Non-Inverting Amplifier.ms14`
- `Colpitts Oscillator.ms14`
- `Passive First-Order Low-Pass Filter.ms14`
- `Second Order Active Low Pass Filter.ms14`

## Requirements

To open and run these files, install circuit simulation software that supports the `.ms14` format.

## How to Use

1. Clone or download this repository.
2. Open any `.ms14` file in your compatible simulator.
3. Run the simulation and analyze outputs based on your study or lab objective.

## Purpose

This repository is intended for learning, practice, and reference in analog circuit design and simulation.
